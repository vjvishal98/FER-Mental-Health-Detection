Try it on your machine

Run the dashboard locally.

Clone the repository, install its dependencies, then start Streamlit.

git clone https://github.com/vjvishal98/FER-Mental-Health-Detection.git
cd FER-Mental-Health-Detection
pip install -r requirements.txt
python -m streamlit run dashboard.py --server.port 8502

The model checkpoint is not included in the repository. Without valid weights, predictions are not meaningful. This research demo is not a medical or mental-health diagnostic tool.
