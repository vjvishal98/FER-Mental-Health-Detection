Place your custom assets in this folder to get an exact visual match with the design screenshots.

Recommended filenames (dashboard.py expects these names):

- Inter-Regular.woff2   (optional; recommended for exact font)
- Inter-Bold.woff2      (optional; recommended for exact font)
- logo.svg              (EmotiSense logo shown in the header)
- icon_image.svg        (card icon for Upload Image)
- icon_video.svg        (card icon for Upload Video)
- icon_camera.svg       (card icon for Live Camera)

Notes:
- If the font files are not present, the app will fall back to Google Fonts (Inter) via the included link tag.
- SVG icons should be simple 48x48 viewBox icons; the app will use them in place of emoji placeholders.
- After you upload the assets, refresh the Streamlit app to see them applied.
